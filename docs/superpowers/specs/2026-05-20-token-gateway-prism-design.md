# 赛隆AIGC Token Gateway 棱镜品牌层设计规格

## 目标

为 `newapi` 和 `sub2api` 两个站点建立同一套“赛隆AIGC”视觉系统，解决当前页面仍像通用站点模板的问题。设计要有科技感和品牌识别度，同时保证深色和浅色模式下的文字、按钮、表格、表单都清晰可读。

## 已确认方向

采用“C 棱镜品牌层”作为主方向。

核心记忆点：

- 光谱棱镜：青蓝、紫、玫红构成品牌主视觉。
- 斜切结构：公开首页使用斜向流光、棱镜切面和轻微背景动效。
- 品牌水印：公开首页保留低对比 `赛隆AIGC` 或 `AIGC` 背景字样。
- 清晰控制台：内部页面只保留少量光谱激活态，不做大面积炫光。

## 视觉原则

1. 公开首页可以更有冲击力，内部页面必须更耐看。
2. 渐变只用于品牌层、主按钮、激活菜单和关键状态点。
3. 正文、表格、表单不使用渐变文字。
4. 所有按钮必须满足“背景能明确承托文字”的要求。
5. 深色和浅色使用同一套语义色，不为浅色模式简单反相。
6. 动效要持续可见但不遮挡内容，内部页面少动效或无动效。

## 色彩系统

主光谱色：

- Cyan: `#38bdf8`
- Violet: `#a78bfa`
- Rose: `#fb7185`

深色基础：

- Page: `#080d18`
- Surface: `rgba(255,255,255,0.07)`
- Text strong: `#f8fbff`
- Text body: `rgba(239,248,255,0.76)`
- Text muted: `rgba(239,248,255,0.58)`
- Border: `rgba(255,255,255,0.13)`

浅色基础：

- Page: `#f2f6ff`
- Surface: `rgba(255,255,255,0.72)`
- Text strong: `#162033`
- Text body: `#52627a`
- Text muted: `#65758b`
- Border: `rgba(99,102,241,0.14)`

语义色：

- Primary action: `linear-gradient(135deg, #4adeff, #9aa7ff 52%, #ff8caf)`
- Danger action: `linear-gradient(135deg, #fb7185, #c084fc)`
- Success badge: cyan background with dark text in both modes
- Warning badge: yellow background with dark text in both modes
- Disabled: low-saturation gray, never bright gradient

## 公开首页设计

公开首页包含：

- 顶部玻璃导航，品牌 logo 和 `赛隆AIGC` 清晰可读。
- 首页、控制台、模型广场、文档、关于等入口使用低对比胶囊，不与主按钮抢视觉。
- Hero 使用光谱棱镜背景、斜切流光和低对比品牌水印。
- 标题使用纯色高对比文字，避免渐变标题影响可读性。
- 主按钮使用光谱渐变，文字使用深色。
- 次按钮使用玻璃底，深色模式文字近白，浅色模式文字深蓝灰。
- 移动端导航可分行或横向滚动，不能挤压文字到 0 宽。

公开首页动效：

- 允许背景棱镜流光、少量光线扫过、轻微水印呼吸。
- 动效层必须 `pointer-events: none`。
- 动效层不能盖住按钮、输入框和主要正文。
- 尊重 `prefers-reduced-motion`，降低或关闭动画。

## 内部页面设计

内部页面包括控制台、令牌管理、模型广场、渠道配置、账单用量、系统设置、登录/注册和表单弹窗。

内部页规则：

- 左侧或顶部导航使用稳定深浅 surface。
- 当前激活菜单使用光谱渐变。
- 非激活菜单只用低对比底色和清晰文字。
- 顶部搜索框和工具按钮使用可读边框和 surface。
- 指标卡、表格、模型卡、表单输入使用统一圆角和低对比边框。
- 表格行必须有清晰分隔，不能被背景光效干扰。
- 表单 label、placeholder、输入值需要三档文字层级。
- 弹窗背景必须比页面 surface 更实，避免浮层内容混在背景中。

按钮规则：

- 主按钮：光谱渐变，深色文字 `#08111f`。
- 次按钮：深色模式使用 `rgba(255,255,255,0.08)`，浅色模式使用 `rgba(255,255,255,0.72)`。
- 危险按钮：粉玫渐变或实色 rose，白色文字。
- 禁用按钮：灰色背景，低对比文字，不使用光谱。
- 图标按钮：必须有可见边框或实底，不能透明飘在复杂背景上。

## 适配范围

需要覆盖：

- `http://43.155.249.112:18088/` 的 NewAPI 首页、登录注册、控制台、模型广场和表单控件。
- `https://token.cylonai.cn/home` 的 Sub2API 首页、登录注册、控制台和内部配置页。

当前实现方式仍以 nginx 注入 CSS/JS 为主，不直接改容器镜像内源码，除非现有注入无法稳定覆盖关键页面结构。

## 技术约束

- 不修改数据库。
- 不修改业务容器运行参数。
- 不引入会造成浏览器卡顿的全页面无限 MutationObserver。
- CSS 要优先使用语义化选择器和低风险兜底选择器。
- JS 只负责品牌名、图标和必要背景层挂载。
- 对 `sub2api` 和 `newapi` 共享一套主题变量，但允许针对具体页面结构做少量 scoped override。

## 验证标准

上线前必须验证：

- 两个 nginx 配置 `nginx -t` 通过并 reload 成功。
- CSS/JS 版本号更新，浏览器实际加载新版本。
- 桌面和手机端截图检查公开首页。
- 桌面和手机端检查内部页面至少一个控制台页、一个列表页、一个表单/弹窗页。
- 深色和浅色模式都可读。
- 主按钮、次按钮、危险按钮、禁用按钮文字清楚。
- 导航项不截断、不重叠、不出现 0 宽入口。
- 背景动效在加载后仍存在，但不遮挡点击和阅读。
- 页面文本不存在 `赛隆AIGCGC` 这类重复污染。
- 页面文本不存在旧品牌 `塞隆AI`。

## 不做事项

- 不把所有页面都做成强烈渐变。
- 不在内部表格和表单里使用大面积动画。
- 不使用浅色模式下难读的淡灰文字。
- 不为了炫酷牺牲按钮可读性。
- 不把首页设计照搬到后台。
