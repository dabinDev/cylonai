# 赛隆 AI 品牌总官网重写设计规格

## 背景

当前官网以 3D 粒子、Canvas 网络动画、自定义光标和滚动驱动动效为主要视觉表达。项目代码中首页由 `components/HomeContent.tsx` 统一包裹为客户端组件，并加载 `HeroCanvas`、`ServicesSection3D`、`NeuralTraining`、`CustomCursor` 等高成本交互模块。这些实现强化了视觉冲击，但不适合企业官网的首屏加载、信息传达和长期产品扩展。

本次重写采用已确认的方案 A：`cylonai.cn` 作为赛隆 AI 品牌总官网，首页承载产品矩阵入口，风格参考腾讯云式企业科技官网。目标是让访客快速理解赛隆的产品体系，并通过轻量、清晰、稳定的页面体验建立企业可信度。

## 目标

1. 将当前官网从视觉演示型页面重写为企业转化型官网。
2. 以赛隆 AI 品牌总官网为主站定位，承载多个产品入口。
3. 在首页明确展示三个核心产品方向：塞隆视创、Cyroute、拾光视频。
4. 移除首页重动效和高成本渲染，显著降低首屏负担。
5. 保留现有博客和文章系统作为资讯内容入口。
6. 为后续独立产品官网和子域名跳转留下清晰结构。

## 非目标

1. 本阶段不实现三个产品的完整独立官网。
2. 本阶段不重写后台文章管理系统。
3. 本阶段不引入新的 3D、Canvas 或复杂动画库。
4. 本阶段不做复杂多语言、账户体系或控制台功能。
5. 本阶段不删除历史 3D/Canvas 组件文件，除非实现计划中确认它们已无任何引用且删除风险可控。

## 站点定位

主站名称：赛隆 AI

主站定位：面向企业和创作者的 AI 产品矩阵，连接内容创作、视频生产和企业级模型接入服务。

推荐首屏标题：

> 赛隆 AI 产品矩阵

推荐首屏副标题：

> 连接 AI 内容创作、视频生产与企业级模型接入服务

主 CTA：

> 联系我们

次 CTA：

> 查看产品

## 信息架构

首页按云厂商官网的信息层级组织，从品牌定位到产品矩阵，再到解决方案、能力优势、资讯和联系转化。

### 顶部导航

导航项：

- 首页
- 产品矩阵
- 解决方案
- 资讯动态
- 关于我们
- 联系我们

桌面端使用白底固定导航，右侧放置蓝色主按钮。移动端使用轻量菜单，不引入复杂抽屉动画。

### 首屏

首屏承担品牌定位和转化入口，不使用全屏 Canvas 或 Three.js。视觉上使用浅蓝到白色的静态背景、细网格或简化的产品能力面板。

内容包括：

- 品牌标题
- 一句话定位
- 两个 CTA
- 简短可信指标或能力标签，例如：企业级 API 分发、AI 内容生产、视频智能剪辑、定制化交付

### 产品矩阵

展示三个产品方向，每个产品使用统一卡片结构：

- 产品名称
- 简短定位
- 典型场景
- 当前状态或访问入口
- 操作按钮

产品定义：

1. 塞隆视创  
   定位：AI 视觉创作与内容生产平台。  
   入口：`https://memo.cylonai.cn`

2. Cyroute  
   定位：企业级 API 中转与模型接入平台。  
   入口：`https://new.cyroute.cn`、`https://sub.cyroute.cn`  
   展示方式：在同一产品卡内区分两套平台入口，避免在首页拆成两个独立产品造成理解负担。

3. 拾光视频  
   定位：AI 视频剪辑与智能成片工具。  
   入口：首版可显示“即将上线”或预留独立官网入口。

### 解决方案

解决方案不做过度行业化，先围绕赛隆已有和计划中的能力组织：

- AI 内容创作与视觉生产
- AI 视频剪辑与智能成片
- 企业 API 中转与模型统一接入
- 模型分发、权限控制与用量管理
- 企业定制化交付

每个方案使用标题、说明和 3 个要点展示，保持信息密度和扫描效率。

### 能力优势

能力优势用于替代当前官网中过多的炫技动效，强调企业服务可信度：

- 轻量稳定：去除首页重型渲染，优先保障加载速度。
- 产品矩阵清晰：主站统一承载多个 AI 产品入口。
- 企业级服务：面向 API 接入、模型分发、权限和用量管理等场景。
- 内容生产经验：覆盖视觉创作和视频剪辑相关产品方向。
- 可持续扩展：后续产品官网、文档、案例和控制台入口可按模块追加。

### 资讯动态

保留现有博客系统，首页展示最新 3 篇已发布文章。博客列表页和文章详情页继续使用当前数据模型与 SEO 结构，视觉样式调整为新官网风格。

### 联系转化

首页底部和导航 CTA 均导向联系咨询。现有联系弹窗可以保留，但视觉需要改为白底企业风，并确保移动端可用。

## 视觉方向

整体风格：腾讯云式企业科技风。

设计原则：

- 白底为主，蓝色作为品牌主色，浅灰用于分区和边框。
- 少量深蓝区域可用于底部 CTA 或页脚，但不让整站变成暗色科技风。
- 卡片圆角控制在 8px 左右，减少过度圆润和漂浮感。
- 使用线性图标、简洁标签和清晰的按钮层级。
- 页面信息密度高于当前版本，减少超大字号和空泛口号。
- 不使用粒子、光标追踪、矩阵雨、滚动汇聚等演示型动效。

建议色彩：

- 主色：`#006EFF` 或接近腾讯云蓝的高饱和蓝
- 文本主色：`#1F2937`
- 次级文本：`#5F6B7A`
- 背景：`#FFFFFF`、`#F5F8FC`
- 边框：`#E5EAF3`
- 深色区：`#0B1F3A`

## 性能重构

首页必须从客户端重型页面改为以 Server Component 为主体的轻量页面。

需要从首页移除引用：

- `HeroCanvas`
- `ServicesSection3D`
- `ServiceCard3D`
- `ServicesBg`
- `NeuralTraining`
- `CustomCursor`

新的首页建议结构：

- `app/page.tsx`：继续服务端获取最新文章。
- `components/HomeContent.tsx`：如果保留，应拆成轻量组合组件；优先改为 Server Component。
- `components/Header.tsx`：仅保留移动端菜单和联系按钮所需客户端逻辑。
- `components/ContactModal.tsx`：保留为 Client Component。
- 新增或重写静态首页区块组件：Hero、ProductMatrix、Solutions、Advantages、BlogPreview、CTA、Footer。

动画限制：

- 允许按钮 hover、卡片 hover、轻量 transition。
- 允许非阻塞的 CSS 背景细节。
- 不允许首页加载 Three.js、React Three Fiber、postprocessing 或自绘全屏 Canvas。
- 不允许依赖滚动位置每帧更新页面状态。

## 组件边界

推荐组件拆分：

- `BrandHeader` 或重写 `Header`：导航、移动端菜单、联系入口。
- `BrandHero`：首屏定位、CTA、能力标签。
- `ProductMatrix`：三个产品卡片和域名入口。
- `SolutionsSection`：解决方案网格。
- `AdvantagesSection`：企业能力优势。
- `BrandCta`：底部联系转化。
- `Footer`：产品、资源、联系方式、备案或版权信息。

组件设计要求：

- 内容数据优先使用数组常量，便于后续维护。
- 静态展示组件默认不使用 `"use client"`。
- 只有确实需要状态的组件才使用客户端组件。
- 产品域名作为明确链接或禁用状态展示，避免无效跳转。

## 验收标准

功能验收：

- 首页明确呈现赛隆 AI 品牌总官网定位。
- 首页展示塞隆视创、Cyroute、拾光视频三个产品方向。
- Cyroute 卡片同时展示 `new.cyroute.cn` 和 `sub.cyroute.cn` 两套入口。
- 首页保留最新文章预览。
- 联系入口在桌面端和移动端都可用。

视觉验收：

- 页面整体为白底、蓝色主色、浅灰分区的企业风格。
- 不再呈现当前版本的大面积暗色粒子、发光卡片、矩阵雨和自定义光标。
- 卡片、按钮、导航样式一致，信息可快速扫描。

性能验收：

- 首页不再引用 `HeroCanvas`、`ServicesSection3D`、`ServiceCard3D`、`ServicesBg`、`NeuralTraining`、`CustomCursor`。
- 首页初始渲染不加载 Three.js、React Three Fiber 或 postprocessing。
- 首页没有基于 `scrollY` 的全局滚动状态刷新。
- `npm run build` 成功。

代码验收：

- 静态首页区块尽量为 Server Component。
- 仅移动端菜单、联系弹窗等交互使用 Client Component。
- 不修改无关后台文章管理逻辑。
- 不回滚或覆盖用户未提交的无关文件变更。
